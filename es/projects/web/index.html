  • contigo

    Aprende un idioma, contigo. Primero solo, después con quien quieres.

    Web

    Qué hace
    • Cada unidad empieza con una tarea que haces solo, y cada respuesta se corrige al instante. El primer curso es de inglés, para quien habla español.
    • Escuchas cada frase, también más despacio, y te grabas. La grabación no sale de tu teléfono.
    • Quien enseña abre la clase y ve, con tu permiso, lo que hiciste y lo que fallaste.

    Dónde funciona. Una app web en el navegador. La app para iPhone todavía no está en la App Store.

  • FERRO

    Una app web para entrenar: rutinas, series y carnet del torno.

    Web

    Qué hace
    • 233 ejercicios con vídeo, descritos en italiano, inglés y español.
    • El código del torno lo genera el móvil, así que el carnet funciona sin cobertura.
    • Puedes enviar una rutina entera a otra persona como enlace o código QR. No hacen falta servidor ni cuenta.

    Dónde funciona. Una app web para iPhone, que se añade a la pantalla de inicio.

  • vesta

    Pruébate tu ropa en una foto tuya. Hecha junto a Gianmattia Barone.

    Web · macOS

    Qué hace
    • Funciona en el navegador, sin cuenta. Ninguna foto sale del dispositivo.
    • Una versión para Mac genera la imagen con la prenda puesta en unos noventa segundos.
    • El análisis del color de la piel en CIELAB propone una estación y una paleta.

    Dónde funciona. Una app de navegador, instalable también en la pantalla de inicio del iPhone. La versión para Mac necesita Apple Silicon.
