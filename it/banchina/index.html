Tema

I tuoi server web locali, in una finestra.

Banchina trova i tuoi progetti web. Avvii o fermi ogni server da lì, senza aprire il Terminale.

Vedi il codiceCompila per macOS

App nativa per macOS, open source. SwiftUI, macOS 14 o successivo, nessun account, nessuna telemetria.

Guarda cosa sta girando prima di fermare qualcosa.

Il controllo della porta dice a Banchina se un servizio risponde. Il proprietario del processo gli dice se il servizio si può fermare senza rischi.

  • Server che non hai avviato tu

    I server avviati altrove compaiono già come attivi. Banchina non ne prende il controllo e non invia mai un segnale di sua iniziativa.

  • Cerca in più cartelle

    Scansiona luoghi scelti, cartelle utente leggibili o un disco rimovibile.

  • Ferma tutto l'albero

    Ai server che gestisce manda un TERM pulito, aspetta un periodo di tolleranza, poi usa una soluzione di riserva con un limite.

  • Le scansioni girano fuori dalla finestra

    La ricerca nel filesystem, il ciclo di vita dei processi, i log e lo stato di SwiftUI girano su domini di concorrenza separati. Le scansioni si possono annullare.

  • Una finestra, nessun account

    Il tuo catalogo resta in Application Support con permessi privati sui file. Banchina non ha analisi d'uso né telemetria, e nessun servizio nel cloud.

Configurala in quattro passi.

  1. Scegli dove cercare.

    Una cartella, il tuo Mac o un volume esterno.

  2. Controlla cosa è stato trovato.

    Vedi prima il comando, la cartella, il framework e la porta dedotta.

  3. Importa i server di cui ti fidi.

    Modifica argomenti, controlli di salute, ambiente e icona quando serve.

  4. Usa l'interruttore.

    Avvia, guarda stato e log, poi ferma, tutto dalla stessa schermata.

Compilala sul tuo Mac.

Banchina ha licenza MIT. Richiede macOS 14 o successivo e Swift 6. Il repository non ha dipendenze di terze parti; lo script di compilazione crea un'app firmata in locale.

git clone https://github.com/nerln/banchina.git
cd banchina
./build.sh
open Banchina.app
